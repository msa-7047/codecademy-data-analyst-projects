# Codecademy Data Analytics Projects

## Overview

This repository contains data analytics projects and exercises completed as part of the Codecademy Data Analyst learning pathway. The projects cover data analysis, data manipulation, visualisation and SQL, with practical work using Python, Jupyter Notebook and Excel and Tableau.

The aim of this repository is to document my learning, develop my technical skills and build a portfolio demonstrating my ability to explore datasets, identify patterns and communicate findings.

- Python – Data analysis and manipulation

- Tableau – Data visualisation and dashboard development
